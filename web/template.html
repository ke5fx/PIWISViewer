PIWISViewer

Porsche PIWIS 3 vehicle analysis log (VAL / FAP) viewer — renders the log as a readable, filterable, English-translated HTML report.

Drop your log zipfile here or click to choose a file

Accepts the FAP_*.zip written by PIWIS (a bare FAP_*.xml also works). If PIWIS wrote several .zip files, use the one whose name begins with FAP_.

Privacy: your log is processed entirely inside your browser by JavaScript on this page. Nothing is uploaded — the VIN and diagnostic data never leave your machine. The page works offline once loaded.

PIWISViewer on GitHub — public domain. A Windows .exe version is available under Releases.
